# Clean Enterprise — AI RFP System

## Palette
- Page background: #FFFFFF
- Sidebar: #EEF2F7 (pale blue-gray)
- Primary / interactive: #2563EB (enterprise blue)
- Primary foreground: #FFFFFF
- Charcoal text: #20242B
- Muted labels: #5A6478
- Border / hairline: #D1D9E6
- Zebra row alt: #F5F8FC
- Danger / alert: #DC2626

## Typography
- Single family: Inter (Google Fonts), weights 400 / 500 / 600 / 700
- No monospace in the UI
- Tabular numerals for all numeric data
- All-caps micro-labels at 11px / 500 for column headers and sidebar section titles

## Shape & Structure
- Border radius: 6px uniformly
- Borders: 1px solid #D1D9E6
- No shadows (border-only elevation model)
- Left sidebar: fixed-width ~220px, grouped labeled sections
- Dense zebra-striped table is the hero element; charts are secondary
- Filter chips above the table (pill shape, 6px radius)

## Spacing
- Base unit: 4px
- Sidebar padding: 16px
- Table row height: 40px
- Section gaps: 24px

## Tone
- Enterprise, precise, data-forward
- No warm or greige neutrals
- No card/board layouts
- No lavender
